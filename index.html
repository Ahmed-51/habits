Sync with GitHub

Your habits are stored as habits.json in a private GitHub repo, so the data is only readable by you. Every save is a commit, which means you get full history and can roll back any day. See SETUP.md for how to create the repo and the token.

Fine-grained token, that one repo only, Contents: read and write.

The token is encrypted with your passphrase before it touches storage, so it is never held in the clear. You will be asked for the passphrase once per browser session.

Enter your passphrase to unlock this browser's access token.

Filling the battery one step at a time — click a cell in the month sheet, press 1–9, or click a battery segment directly (clicking the topmost lit segment un-fills it). The big button is the all-or-nothing switch.

The weekly target. The battery is always today — that doesn't change. The week card underneath counts every tick across the whole week against one target, so a bad Tuesday doesn't write off the week: a strong Saturday can still cover it. Click the target number to change it, or the date range to switch between Monday and Sunday starts. Weeks spanning two months are handled; each day counts against its own month's habit list.

Sync (optional). The chip in the toolbar says Local only until you connect a private GitHub repo — click it to set that up. Once connected, edits push a couple of seconds after you stop clicking, and any browser you unlock pulls the same data. It still works offline and catches up later. Leave it off and nothing changes.

Storage. Everything is written to this browser's local storage the moment you click, so nothing is lost if you close the tab. Save writes a habits.json backup — put that inside your Google Drive folder and Drive keeps it synced across machines. Load brings it back.

Months. Each month stores its own snapshot of the habit list, so editing this month's habits never rewrites your history. New months start from your current list.
